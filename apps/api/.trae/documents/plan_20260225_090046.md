I have identified the causes for both the library sorting issue and the missing profile stats.

### **1. Library Sorting Issue**
**Problem:** When you read a chapter, the backend updates your reading history but **fails to update the "Last Read" timestamp** on the item in your library. Since the library sort relies on this timestamp, the manga doesn't move to the top.
**Solution:**
*   **Backend:** Modify `HistoryService` to update the `LibraryEntry`'s `lastReadAt` timestamp whenever you read a chapter.
*   **Frontend:** Change the default library sort order from "Date Added" to **"Last Read"** so that recently read items automatically appear at the top.

### **2. Profile Stats Issue (0 Stats)**
**Problem:**
*   **Reading Time:** The app currently doesn't track how long you spend reading. The "Reading Time" stat stays at 0 because no duration data is ever sent to the server.
*   **Chapters Read:** This stat counts chapters read *today*, but since the `lastReadAt` wasn't being updated consistently on the library entry, and the frontend only fetches stats once on startup, this often appears as 0.
*   **Stale Data:** The Profile screen doesn't refresh your stats after you read; it only loads them when you first log in.

**Solution:**
*   **Frontend (Tracking):** Add a timer to the `MangaReaderScreen` to track how long you spend reading. This duration will be sent to the server every time your progress is saved.
*   **Backend (Storage):** Update the database to store this reading duration in your user profile.
*   **Frontend (Display):** Add a "Pull to Refresh" feature to the Profile screen so you can instantly see your updated stats.

### **Implementation Plan**

#### **Backend Changes**
1.  **Update `HistoryService`**:
    *   Ensure `syncHistory` updates `LibraryEntry.lastReadAt`.
    *   Add logic to accumulate `readingTime` in the user's `readingStats`.
2.  **Update `UsersService`**:
    *   Adjust `getUserStats` to correctly calculate reading time from the stored data.
3.  **Update DTOs**: Add `readingTimeMs` to the history sync payload.

#### **Frontend Changes**
1.  **`OfflineLibraryProvider`**: Set default sort to `'last_read'`.
2.  **`MangaReaderScreen`**: Implement a `Stopwatch` to measure reading duration and send it with progress updates.
3.  **`MangaRepository` & `LibraryApi`**: Update methods to transmit the reading duration.
4.  **`ProfileScreen`**: Wrap the profile view in a `RefreshIndicator` to allow manual refreshing of stats.
5.  **`AuthProvider`**: Add a `refreshUserStats()` method to fetch the latest numbers from the server.
