### **Plan of Action**

1.  **Fix** **`FileService.requestStoragePermission`** **Logic:**
    *   **Current Issue:** It only returns `true` if the permission was *denied and then granted* in the current call. If it was *already* granted, the `if` block is skipped, and it falls through to check legacy `Permission.storage`, which fails on Android 13+.
    *   **Fix:** Add an explicit check: `if (await Permission.manageExternalStorage.isGranted) return true;` *before* the denial check.
    *   Also ensure `Permission.storage` is only checked as a fallback if `manageExternalStorage` is not applicable or denied.

2.  **Add Robustness for Directory Creation:**
    *   In `_getBaseDirectory`, catch exceptions when checking `exists()` or `create()`. If checking external storage fails (due to weird OS states or permission bugs), fallback to internal storage gracefully instead of crashing or returning a path that will fail later.

3.  **Refine** **`MangaRepository`**:
    *   Keep the permission check, but ensure the error message is clear.

### **Why this fixes the issue:**
The user logs show `Exception: Storage permission denied`. This exception is thrown in `MangaRepository` when `fileService.requestStoragePermission()` returns `false`.
It returns `false` because:
1.  The user granted `MANAGE_EXTERNAL_STORAGE`.
2.  The code checks `isDenied`. It is **false** (because it's granted).
3.  The code skips the `manageExternalStorage` block.
4.  The code checks `Permission.storage`. On Android 13+, this is often denied/restricted (replaced by photos/videos/audio permissions).
5.  It requests `Permission.storage`. The OS denies it or it fails.
6.  The function returns `false`.

By adding the `isGranted` check at the top, we short-circuit correctly.

### **Proposed Code Change in** **`FileService`**

```dart
  Future<bool> requestStoragePermission() async {
    if (!Platform.isAndroid) return true;

    // 1. Android 11+ (API 30+): Manage External Storage
    if (await Permission.manageExternalStorage.isGranted) {
      return true;
    }

    if (await Permission.manageExternalStorage.status.isDenied || 
        await Permission.manageExternalStorage.status.isRestricted || 
        await Permission.manageExternalStorage.status.isPermanentlyDenied) {
        // Try to request it
        final status = await Permission.manageExternalStorage.request();
        if (status.isGranted) return true;
    }

    // 2. Android 10 and below: Legacy Storage Permissions
    // If manageExternalStorage is not applicable (e.g. older Android), or if the user somehow
    // is on a device where both exist but one failed, we check standard storage.
    
    if (await Permission.storage.isGranted) {
      return true;
    }

    final status = await Permission.storage.request();
    return status.isGranted;
  }
```
