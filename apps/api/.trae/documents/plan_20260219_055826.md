I will implement the nested comments feature with photo support by enabling the existing user/auth system and adding a new Comments module.

### **1. Enable Core Modules**
- **Action:** Uncomment `UsersModule`, `AuthModule`, and `PrismaModule` in `app.module.ts`.
- **Reason:** These modules are already implemented but disabled. They are required for user authentication and database access.

### **2. Database Schema (`prisma/schema.prisma`)**
- **Action:**
  - Create a `Comment` model with fields for:
    - Content (`content`)
    - Photo attachments (`images` as string array)
    - Relations to `User` (author)
    - Relations to `Comment` (parent/replies for nesting)
    - External references: `mangaId` and `chapterId`
  - Update `User` model to include a relation to `Comment`.
- **Action:** Run `npx prisma migrate dev` to apply changes.

### **3. File Storage (`UploadsModule`)**
- **Action:** Create a simplified local file storage system.
  - Configure `Multer` (via NestJS) to save uploaded images to a root `./uploads` directory.
  - Update `app.module.ts` to serve files from `./uploads` at the `/uploads` URL path (using `ServeStaticModule`).

### **4. Comments Feature (`CommentsModule`)**
- **Action:** Create `CommentsController` and `CommentsService`.
- **Endpoints:**
  - `POST /comments`: Create a comment. Supports `multipart/form-data` for uploading images along with text.
  - `GET /comments/:mangaId/:chapterId`: Fetch comments for a specific chapter.
    - Will support fetching nested replies (threaded view).
  - `DELETE /comments/:id`: Delete a comment (author only).

### **5. Dependencies**
- **Action:** Install `multer` and `@types/multer` to handle file uploads.
