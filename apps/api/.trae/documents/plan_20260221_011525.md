    * Handle **Avatar/Banner Uploads**: Use `Multer` (already configured for comments) to save files to `uploads/` and update `avatarUrl`/`bannerUrl`.

          * Update `username`, increment `usernameUpdateCount`, set `usernameUpdatedAt = now()`.

  * `PATCH /user/profile`:
    * Accepts `multipart/form-data`.
    * Fields: `username`, `bio`.
    * Files: `avatar`, `banner`.
    * Uses `FileInterceptor` (or `FileFieldsInterceptor` for multiple files).
