## Slow or unavailable sources

A new title or uncached chapter still needs the source to respond. Try another connection or source. Previously saved details should stay available; pull down to refresh when you want updated metadata.

## Library looks empty

Check the signed-in account, selected category and active filters. A new device may not have synced the account's entries yet. Do not clear app storage as a first troubleshooting step: it can remove device-only downloads.

## Settings change back

Check that you are using the same account. Display settings are account-scoped. Change the setting, reopen the page and restart the app. If the setting still reverts, report the exact setting, build number and whether the network was available.

## Comments cannot be sent

Check your connection and sign-in, then retry the preserved draft. Use no more than five static images and choose a smaller image if the upload limit is reached. User-facing errors should not display backend addresses or raw server responses.

## Test a new beta

Install it as an update. Check your library, grid choice and account name, force-stop the app from Android Settings, and reopen it. Repeat after a device restart. Try a saved chapter offline, test a mention and image preview, and report any steps that fail.

## Send a useful report

Include the app version/build, device model, Android or iOS version, network conditions and steps to reproduce. You can attach a screenshot after removing personal information. Never send your access token, password or signing credentials.
