I will implement the User Library, Filtering/Sorting, Categories, User Display Preferences, and Search functionality by adding new modules and updating the database schema.

### **1. Database Schema Updates (`prisma/schema.prisma`)**

* **`User`** **Model Update:**

  * Add `preferences` field (Json) to store display settings.

  * Add relation to `Category`.

  * Add relation to `LibraryEntry`.

* **`LibraryEntry`** **Model (New):**

  * Stores the user's manga library.

  * Fields: `id`, `userId`, `mangaId` (external ID), `title`, `thumbnailUrl`, `author`, `sourceId` (to know which extension to use).

  * Status Flags: `isUnread` (Boolean), `isStarted` (Boolean), `isBookmarked` (Boolean), `isCompleted` (Boolean).

  * Counts: `unreadCount` (Int), `downloadedCount` (Int), `totalChapters` (Int).

  * Metadata: `language` (String).

  * Timestamps: `lastReadAt`, `lastUpdatedAt`, `dateAddedAt` (default `now()`).

  * Relations: `User`, `Category` (via a join table or array of IDs if simplified, but many-to-many is better).

* **`Category`** **Model (New):**

  * Fields: `id`, `name`, `userId`.

  * Relations: `User`, `LibraryEntry` (Many-to-Many).

### **2. Create Modules**

* **`LibraryModule`**:

  * **Controller**: `LibraryController`

    * `GET /api/user/library`: Returns list of library entries.

      * Handles query params for **Filtering** (`filter_downloaded`, `filter_unread`, etc.).

      * Handles query params for **Sorting** (`sort_by`, `order`).

      * Handles query params for **Search** (`search`).

    * `POST /api/user/library`: (Implicit need) Add manga to library.

    * `PUT /api/user/library/:id`: Update status/counts (e.g., when a chapter is read).

    * `DELETE /api/user/library/:id`: Remove from library.

  * **Service**: `LibraryService`

    * Implements the logic for fetching, filtering, sorting, and searching using Prisma queries.

* **`CategoriesModule`**:

  * **Controller**: `CategoriesController`

    * `GET /api/user/categories`: List user categories (optional `include_count`).

    * `POST /api/user/categories`: Create category.

    * `PUT /api/user/categories/:id`: Update category name.

    * `DELETE /api/user/categories/:id`: Delete category.

    * `POST /api/manga/:mangaId/category/:categoryId`: Add manga to category (bridge to LibraryEntry).

  * **Service**: `CategoriesService`

    * CRUD operations for categories.

* **`UsersModule`** **(Update)**:

  * Add endpoints for Preferences.

  * `GET /api/user/preferences`: Retrieve `user.preferences`.

  * `PUT /api/user/preferences`: Update `user.preferences`.

### **3. Implementation Details**

* **Filtering Logic**: Build a dynamic Prisma `where` clause based on query booleans.

* **Sorting Logic**: Map `sort_by` params (e.g., `alphabetical` -> `title`) to Prisma `orderBy`.

* **Search Logic**: Use `contains` (case-insensitive mode) for `title` and \`author
