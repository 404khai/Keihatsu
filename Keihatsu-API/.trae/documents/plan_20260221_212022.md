I have identified the issues preventing WeebCentral and Atsumaru from fetching mangas. Both require updates to handle modern anti-bot protections and dynamic content.

### Analysis & Issues
1.  **PuppeteerService (Core Issue)**:
    *   **Detection**: It launches in standard headless mode with a fixed User-Agent, making it easy for Cloudflare to block.
    *   **Timeout Handling**: It swallows timeout errors when waiting for selectors, returning invalid HTML (e.g., the "Just a moment..." challenge page) instead of failing or retrying.
    *   **Resource Blocking**: Blocking stylesheets can break some SPAs that rely on CSS for layout-dependent JS execution.

2.  **WeebCentral Extension**:
    *   **Cloudflare Block**: Heavily protected. The current `PuppeteerService` configuration is likely failing the challenge.
    *   **Selectors**: The `waitForSelector` strategy is brittle.

3.  **Atsumaru Extension**:
    *   **Wrong Protocol**: It uses `HttpSource` (Axios) but `atsu.moe` is a modern site that likely requires JavaScript/Puppeteer.
    *   **Generic Selectors**: The CSS selectors are too generic (`.entry`, `.manga-item`) and don't match the specific structure of `atsu.moe`.
    *   **Missing Implementation**: It doesn't override the fetch methods to use Puppeteer, so it falls back to blocked HTTP requests.
