### **Why this happens**

* **Double Path**: The `mangaId` from some sources (like "manhua/ordeal") contains a slash. When plugged into a path string `downloads/$sourceId/$mangaId/...`, the slash is treated as a directory separator.

* **Missing Thumbnail**: The `DownloadQueueScreen` assumes `mangaThumbnail` is always a local file path (`Image.file`), but often the download starts with just the remote URL provided by the previous screen.
