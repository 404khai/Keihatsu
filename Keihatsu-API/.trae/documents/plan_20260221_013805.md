I will replace the local file storage with Cloudinary for user profile pictures and banners.

### **1. Dependencies**

* Install `cloudinary` and `streamifier` (and types).

### **2. Cloudinary Module**

* Create a `CloudinaryModule` and `CloudinaryService`.

* **Provider**: Register the Cloudinary `v2` configuration using environment variables.

* **Service**: Implement an `uploadImage(file: Express.Multer.File)` method that:

  * Takes a file buffer.

  * Uses `streamifier` to pipe the buffer to `cloudinary.uploader.upload_stream`.

  * Returns the `secure_url` of the uploaded image.

### **3. Update User Profile Controller**

* Modify `UserProfileController` to use `MemoryStorage` instead of `DiskStorage`.

  * Remove the `diskStorage` configuration from the `FileFieldsInterceptor`.

  * Multer will now pass the file `buffer` to the service.

### **4. Update Users Service**

* Inject `CloudinaryService` into `UsersService`.

* Update `updateProfile`:

  * Iterate over `files.avatar` and `files.banner`.

  * Call `cloudinaryService.uploadImage(file)` for each.

  * Save the returned Cloudinary URL to `avatarUrl` / `bannerUrl` in the database.

### **Environment Variables You Need to Provide**

You will need to add these to your `.env` file:

```env
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
```
